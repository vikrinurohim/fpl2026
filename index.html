Akumulasi Starting XI sepanjang musim · buka baris bertanda ▶ untuk melihat isi (lihat panduan di bawah)

📘 Panduan baca (untuk yang belum terbiasa JSON)
1. Pilih Manager di dropdown di atas.
2. Yang tampil adalah data line-up-nya sepanjang musim, disusun berlapis.
3. Tanda ▶ = masih tertutup · klik tulisan itu untuk membuka. Tanda ▼ = sudah terbuka · klik lagi untuk menutup.
4. Buka by_gameweek → pilih minggu (0 = GW1, 1 = GW2, dst) → buka players untuk lihat 11 pemain.
5. Di tiap pemain: points = poin yang masuk skor (sudah × captain), points_breakdown = kenapa poinnya segitu, note = kalau ada ganti dari bench.
6. Tombol Copy JSON menyalin semua data ke clipboard (bisa ditempel di WhatsApp / notepad).
